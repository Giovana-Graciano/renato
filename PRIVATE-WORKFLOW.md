# Fluxo privado dos cartões

## Para os amigos
Abra `create.html` e use o código compartilhado pela organizadora.
Depois de criar o cartão, clique em **ENVIAR CARTÃO** e mande o `.json` para a organizadora.

## Para a organizadora
Abra `admin.html`, use o código de admin, importe os JSONs e clique em **PUBLICAR CARDS.JSON**.
Substitua `cards/cards.json` no GitHub pelo arquivo baixado e aguarde o GitHub Pages publicar.

## Importante
GitHub Pages é hospedagem estática. As senhas de `create.html` e `admin.html` são uma barreira de acesso/obscuridade, não autenticação server-side forte. Para uma surpresa de aniversário isso impede o acesso casual, mas não protege contra alguém que inspecione o código-fonte.

O site público não contém mais o Card Factory aberto nem o importador administrativo.
